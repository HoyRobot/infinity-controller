Built from current Pinfinity Web Bluetooth research and current TableBot protocol/firmware research. Version 4 keeps the working v3 foundation but matches the current TableBot basic encoder and start/transport path more closely: 10-byte BLE chunks with 30 ms spacing by default; handshake before version query; 0x05 payload 00 idle stop; 500 ms STOP/PRE timing; 0x04 PRE; 0x01 PATTERN; 0x03 live STOP; fixed Sequence points; basic whole-drill Random flags; and the 465-entry community motor table. Alternate 0x98 and 20-byte transport remain available only as compatibility tests.

First-use safety

Keep access to the robot's physical power switch during the first live test. This page is based on working community protocol research, but your exact robot firmware can still require compatibility tuning. Start with Normal / Topspin / Medium and a center target before calibrating serves.
